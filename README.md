# Central de links — modelo pronto

Este kit cria um endereço estável no GitHub Pages que redireciona para vários destinos do Telegram.

Exemplo:

```text
https://SEUUSUARIO.github.io/SEUREPOSITORIO/?bot=principal
https://SEUUSUARIO.github.io/SEUREPOSITORIO/?bot=principal&src=twitter01
```

Para começar, siga o arquivo `CONFIGURAR.txt`.

Nunca coloque tokens, senhas ou IDs privados no `config.json`, no código ou em commits.
